📱 Installation Instructions:

On Mac (Chrome/Edge):

  1. Open http://localhost:3008 in Chrome or Edge
  2. Look for the install icon in the address bar (⊕ or ⬇️)
  3. Click it and select "Install"
  4. The app will open in its own window

On Mac (Safari):

  1. Open http://localhost:3008 in Safari
  2. Click File → Add to Dock (macOS Sonoma or later)
  3. Or use Share button → Add to Home Screen

Testing Offline Mode:

  1. Install the app first
  2. Open Chrome DevTools (Cmd+Option+I)
  3. Go to Network tab
  4. Check "Offline" checkbox
  5. Refresh the page - you should see the offline page
