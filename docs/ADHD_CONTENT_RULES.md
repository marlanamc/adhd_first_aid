# ADHD-Friendly Content Rules & Guidelines

This document contains all the established rules for creating ADHD-friendly content in the First Aid Kit. These rules have been developed through testing and user feedback to ensure optimal accessibility and effectiveness.

## 🎯 Core Structural Rules

### Bullet Point Limits
- **Maximum 5 bullets per section** - Never exceed this limit
- **No nested bullets with arrows (→)** - Causes cognitive overload
- **Each bullet should be self-contained** - Don't rely on previous bullets for context

### Section Length Limits
- **Step introductions**: Maximum 15 words (for cognitive accessibility)
- **Tips**: Keep concise and actionable
- **Sections**: Use collapsible design to reduce visual overwhelm

### Content Organization
- **Maximum 5 steps per barrier** - Never exceed this limit for cognitive accessibility
- **Start with regulation** - Step 1 must always include nervous system regulation content
- **Logical progression**: Regulate → Acknowledge → Act → Activate → Support
- **Use clear headings** - Users should be able to scan quickly

## 🗣️ ADHD-Friendly Language Rules

### Positive Framing (Never Use "Don't")
- ❌ **Don't**: "Don't try all of these approaches"
- ✅ **Do**: "Pick the ONE approach that feels most doable - your brain will thank you for the focus"
- ❌ **Don't**: "Don't feel bad about this"
- ✅ **Do**: "This feeling is temporary and normal"

### Validation Without Shame
- Always acknowledge ADHD as neurological, not moral
- Use phrases like "your brain works differently" not "you're broken"
- Validate the struggle before offering solutions
- Include phrases like "you've survived 100% of your worst days"

### Direct, Concrete Language
- Use specific actions: "Put everything in one visible pile" not "organize your space"
- Avoid metaphors that require extra processing
- Give immediate, actionable steps
- Use "you" language for direct connection

### Sentence Variety and Flow
- **Vary sentence structures**: Mix short punchy sentences with longer explanations
- **Limit em dashes**: Overuse creates monotonous rhythm - use periods, commas, questions instead
- **Use different sentence types**: Commands ("Let's redirect"), questions ("Tired? Bored?"), statements ("You're not broken")
- **Create reading rhythm**: Alternate between brief and detailed explanations for better cognitive flow
- **Avoid repetitive patterns**: Don't start every bullet the same way or use identical punctuation throughout

### Permission-Giving Language
- "You're allowed to..." / "It's okay to..."
- "Sometimes [behavior] is [valid reason]" 
- "Your brain might be saying 'not now' for good reasons"
- "This doesn't make you broken or lazy"

## 🚫 Content to Avoid

### Banned References
- **No TikTok mentions** - Platform creates comparison and inadequacy
- **No "sweet treats" or candy rewards** - Many users have eating disorders or diabetes
- **No "friend" language** - Can trigger loneliness for isolated users
- **No millennial slang** - Excludes other age groups and can feel forced

### Avoid Shame-Inducing Content
- No "you should" statements without context
- No comparison to neurotypical standards
- No perfectionist language or expectations
- No time pressure or urgency unless specifically helpful

### Don't Include
- Ableist language or assumptions
- References to specific apps that may not be accessible
- Expensive solutions as primary recommendations
- Complex multi-step processes without breaking them down

## ✨ Required Content Elements

### Step 1 Regulation Requirements
- Must include nervous system language ("your nervous system needs...")
- Basic needs check (food, water, movement, rest)
- **Values alignment check** - Include "What really matters here?" or similar values questioning
- Permission to pause/rest
- Safety grounding

### Format Requirements
- **Bold headers** for bullet points with colons: `**Header**: explanation`
- Proper markdown formatting that won't double-bold
- Consistent emoji use with Lucide icon fallbacks
- Clean, scannable layout

### Accessibility Features
- Color-coded sections for different steps
- Collapsible content to reduce overwhelm
- Clear visual hierarchy
- Mobile-friendly design
- Fast loading/validation (under 300ms)

## 🧠 ADHD-Specific Considerations

### Executive Function Support
- Break tasks into micro-steps
- Provide external structure and reminders
- Include body doubling options
- Offer multiple entry points

### Dopamine System Support
- Include interest, urgency, and reward options
- Provide novelty suggestions
- Support hyperfocus patterns when beneficial
- Acknowledge dopamine seeking behaviors

### Sensory Considerations
- Address environment setup
- Include lighting, noise, temperature factors
- Suggest sensory regulation tools
- Acknowledge overstimulation

### Emotional Regulation
- Include nervous system regulation first
- Address rejection sensitivity
- Provide trauma-informed language
- Support emotional overwhelm

## 📊 Quality Standards

### Validation Requirements
- **A+ grade** on fast validator (100% score)
- All formatting rules followed
- Maximum bullet counts respected
- Regulation content included
- No shame-based language

### Content Density
- Aim for 68%+ reduction from original overwhelming content
- Prioritize most actionable, essential items
- Remove redundancy and repetition
- Focus on immediate relief strategies

### User Experience
- Content should feel supportive, not overwhelming
- Should work for crisis moments and calm moments
- Must be scannable for low executive function days
- Should build confidence, not create more shame

## 🔄 Iterative Improvement

### Feedback Integration
- User feedback always trumps theoretical best practices
- Test with actual ADHD users when possible
- Monitor for unintended shame or exclusion
- Adjust language based on community response

### Regular Review
- Audit content quarterly for rule compliance
- Update language as ADHD understanding evolves
- Remove outdated references or approaches
- Ensure accessibility standards remain current

---

**Remember**: These rules exist to serve ADHD brains, not to constrain creativity. When in doubt, ask: "Does this make someone with ADHD feel seen, supported, and capable of taking action?"
