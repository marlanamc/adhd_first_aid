Core Principles - Fixed Format (No Colons)

Correct Format - As It Should Display

✨
Break it way down
Tiny steps are less overwhelming and easier to start

Try: Add a movement or water break between blocks

⏰
Make time visible
Use timers, calendars, and countdowns to anchor your plan

Try: Set a visible 20-30 min timer

📍
Externalize everything
Don't keep your plan in your head, write it down, make it visual

Try: Do one 60-second starter action

🔄
Progress over perfection
Every session counts, even if it's short or messy

Try: Write a 3-step checklist you can reuse

🌱
Support is allowed
Accountability, body doubling, and accommodations are valid tools

Try: Park links in a later window

⏰
Make time visible
Use visible timers and countdowns to anchor pacing

Try: Use a kitchen timer in view

Key Features of Fixed Format:

  • ✅ Title text is bold and on its own line
  • ✅ NO COLON between title and description
  • ✅ Description on second line (not bold)
  • ✅ "Try:" suggestions remain as-is with colon
